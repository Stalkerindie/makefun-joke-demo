## The entry

`main.py` (Python 3.13) writes one joke to `/output/entry.txt`. It is fully deterministic: the text is embedded in the program, with no network access and no randomness.

> I asked my AI agent to review my code. It approved the pull request in two seconds — which is exactly how I knew it hadn't read it either.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
